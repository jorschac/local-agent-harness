# 来源、裁剪与实现对应

调研基线是 [jorschac/hermes-agent @ 67e4d22](https://github.com/jorschac/hermes-agent/tree/67e4d22d83b242ecfb2807ed39e9696ba1b1b0d5)，不是持续漂移的 main。官方后续文档仅辅助，不将新官网全部功能当作此 fork 或本实现已具备。

宿主保留最小工具反馈循环：发出 messages + tool schemas；接受 assistant.tool_calls；校验参数、记录 intent/started/result；写回匹配 tool_call_id 的 role=tool 观察；再次调用模型直到最终回答/明确上限。隐藏推理不是验收产物，以动作和观察事件核验真实执行。

Hermes Gateway 有消息平台、TUI/JSON-RPC 及 OpenAI HTTP/SSE 等不同入口。该题不整包复制 Gateway，而取 CLI → loopback HTTP/SSE → 常驻服务 → OpenRouter 的两层 OpenAI 协议设计。CLI 不在本地创建 AgentLoop；直接工具调用也交给服务。Chat 是有界子集，不是完整透明 OpenAI proxy。

模块：`cli.py` 请求客户端，`daemon.py` 生命周期；`server.py` HTTP/SSE，`runs.py` 单槽调度，`loop.py` 反馈循环，`provider.py` 官方 OpenAI SDK 出站；`plugins.py`/`registry.py` 插件登记与分发；`store.py` SQLite意图和历史，`config.py`/`paths.py` 版本化配置。浏览器/算术业务只在插件目录。

插件子集：`plugin.yaml` 的 manifest_version=2、kind=standalone、provides_tools、config_schema；`register(ctx)` 注册，`ctx.get_config`读取隔离配置，`ctx.register_tool(name,toolset,schema,handler)`暴露OpenAI函数schema。handler接受args与所需上下文，返回JSON字符串。未知manifest字段、名字冲突、不支持schema明确拒绝；不承诺完整Hermes hook、override、依赖管理或OAuth兼容。安装仅复制并登记；显式信任/选择后才运行全信任Python。

浏览器使用CDP Target/Runtime/Page；close只有success is True才归还名额。专用headed Chrome单例与私有profile，不接管用户日常Chrome。任意JS/网络不是安全沙箱。四则运算使用有界解析器和Decimal，不使用eval。
